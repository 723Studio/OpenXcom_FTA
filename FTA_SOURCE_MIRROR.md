# X-Com: From the Ashes engine source mirror

This repository mirrors the GPL-covered engine source from:

`723Studio/From-the-Ashes-monorepo/engine`

It does not contain proprietary FTA content, encrypted content packages,
paid/private art assets, or original X-COM/UFO Defense resources.

Official FTA content packages are distributed separately as generated
encrypted `.oxc` artifacts. Original UFO resources must be provided by
the player from a legally owned copy of X-COM/UFO Defense / UFO: Enemy Unknown.
